OptiPick

A small compiler that learns, from hundreds of generated programs, which order to run its own optimization passes in, instead of using one order an engineer fixed in advance.

Four passes, one program

Constant folding collapses arithmetic already known at compile time. Common subexpression elimination reuses a result instead of recomputing it. Dead code elimination removes any value nothing reads again. Loop invariant code motion pulls a computation out of a loop when nothing inside the loop changes its inputs.     Letting the data choose the order
    
    
    OptiPick generates hundreds of random programs, tries six sensible pass orders on each one, and records which order finishes using the fewest total instruction checks across every pass. A shallow decision tree then learns to predict that order from a few simple properties of a program: how many instructions it has, how many values are already known constants, whether it contains a loop, and how many separate blocks the program has.
